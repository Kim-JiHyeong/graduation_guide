# 순천대학교 졸업요건 확인 AI 서비스

순천대학교 컴퓨터공학과 22학번 졸업요건을 확인하는 웹앱. 전공 과목은 체크박스로 이수 상태를
표시하고, 교양 과목은 직접 입력해서 등록하면 졸업요건 충족 여부를 코드가 정확하게 계산해줍니다.
계산 결과를 바탕으로 AI에게 졸업 관련 질문도 할 수 있습니다.

기획 문서: `../2026 융합 아이디어 캠프/순천대학교 졸업요건 확인 AI 서비스 기획.pdf`

## 핵심 설계 원칙

- **개인정보를 저장하지 않음** — 이름, 학번(뒷자리) 같은 걸 입력받지 않고, **입학년도(22~26학번)**만
  선택. 학과는 현재 컴퓨터공학과로 고정.
- **서버/DB 없음** — 모든 데이터는 브라우저 localStorage에만 저장 (기기별로 분리, 동기화 없음).
- **졸업요건 판정은 AI가 아니라 코드가 정확히 계산** (`src/lib/calculate.ts`). AI는 그 계산 결과를
  받아서 자연어로 설명/상담만 함 — 스스로 학점을 다시 계산하지 않음.
- **수강완료 vs 수강예정 구분** — "지금 상태" 뿐 아니라 "이 과목들을 들으면 졸업할 수 있는가"까지
  확인 가능 (대시보드의 "현재 상태" / "수강예정 포함" 토글).

## 기술 스택

Next.js (App Router) + TypeScript + Tailwind CSS. AI는 OpenAI API (`/api/chat` 서버 라우트에서만
호출, 키가 클라이언트에 노출되지 않음). 배포는 Vercel 권장.

## 실행 방법

```bash
cd frontend
npm install
npm run dev
```

http://localhost:3000 에서 확인. AI 상담 기능을 쓰려면 `frontend/.env.local`에 아래처럼
OpenAI API 키를 넣어야 함 (본인 키 필요 — 이 세션에서 대신 발급/설정하지 않았음):

```
OPENAI_API_KEY=sk-...
```

키가 없어도 AI 상담 탭만 안내 메시지가 뜨고, 나머지 기능(전공/교양 입력, 졸업요건 계산)은 그대로
동작합니다.

## 데이터 반영 출처

컴퓨터공학과 22학번 기준. 순천대학교 「2022학년도 교육과정」책자
(`[별표 1] 학과·학부(전공)별 졸업소요학점 구성표` p.26, 컴퓨터공학과 전공 교육과정편성표 p.157)와
「순천대학교 졸업자격 인증제 운영 지침」(2015.5.18 제정, 2019.11.28 개정)을 근거로 함.
`src/lib/defaultRequirements.ts`에 하드코딩되어 있음.

- 총 졸업학점 130 / 전공(필수+선택) 최소 70 / 전공필수 36(지정과목 12개, 전공선택 19개) / 교양 최소 30
- 졸업자격인증제: 인성예술체육/지역해외봉사/컴퓨터정보화/외국어 4개 영역 중 1개만 100점 이상이면 충족

**22학번 외 입학년도(23~26학번)는 아직 학교 자료로 검증되지 않아서, 지금은 같은 템플릿을 임시로
재사용하고 화면에 경고 문구를 표시합니다.** 실제 학번별 교육과정 자료가 확보되면
`defaultRequirements.ts`의 `buildRequirements()`를 학번별로 분기하도록 확장하면 됨.

## 사용법

1. 입학년도 선택 후 시작 (개인정보 입력 없음)
2. "전공 과목" 탭에서 이수 상태 체크 (미이수 / 수강예정 / 이수완료)
3. "교양 과목" 탭에서 들은(또는 들을 예정인) 교양 과목을 직접 입력
4. "대시보드"에서 현재 상태와 수강예정 포함 상태를 각각 확인, 졸업자격인증제 점수 입력
5. "AI 상담" 탭에서 계산된 현황을 바탕으로 자유롭게 질문
6. "설정"에서 입학년도만 다시 바꿀 수 있음 (그 외 개인정보 입력란 없음)

## 구조

- `frontend/` — Next.js 앱. 지금 사용하는 유일한 코드.
  - `src/lib/types.ts`, `defaultRequirements.ts`, `calculate.ts`, `formatStatus.ts` — 데이터 모델,
    기본 졸업요건, 계산 로직(현재/수강예정 두 버전), AI에게 넘길 요약 텍스트 생성
  - `src/lib/storage.ts` — localStorage 기반 저장 (개인 식별자 없이 단일 프로필)
  - `src/components/` — Onboarding, Header, Dashboard, MajorCourses, GeneralCourses, ChatWidget, Settings
  - `src/app/api/chat/route.ts` — OpenAI 호출 서버 라우트 (API 키는 여기서만 사용)
- `backend/` — 이전에 만들었던 Express + SQLite 서버(회원가입/로그인 방식). 지금은 전혀 사용하지
  않지만 참고용으로 남겨둠.
